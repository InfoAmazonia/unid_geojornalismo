# Redução da água na bacia do Alto Juruena

Os arquivos e scripts utilizados na análise do volume d’água da Bacia do Alto
Juruena estão organizados nesta pasta com a seguinte estrutura:

- `dados`: dados de cobertura, superfície de água e dados auxiliares, com eventuais filtros ou cruzamentos
- `tidy_dados`: scripts em R com arrumações dos dados
- `analises`: relatório em Quarto com os principais achados, com resultados em
  html e docx.
